# البدء

ابنِ تكاملًا مع Bid في أقل من 15 دقيقة.

## ما ستحصل عليه في النهاية

مسار عمل متكامل يرسل فيه المستخدم رسالة إلى الأداة التي تختارها (n8n أو Make.com أو روبوت محادثة مخصص أو Claude Desktop أو Cursor)، وبعد حوار قصير مع وكيل مساعد Bid يحصل على رابط طلب عروض حقيقي، دون أن يفتح تطبيق Bid أبدًا.

## 1. إنشاء حساب وتوثيق شركتك

1. سجّل حسابًا جديدًا عبر [bidapp.sa/signup](https://bidapp.sa/signup).
2. أكمل إعداد شركتك (الاسم القانوني، رقم السجل التجاري، رقم ضريبة القيمة المضافة).
3. ارفع مستندات التوثيق. لا يمكنك نشر طلبات العروض قبل أن تصبح شركتك `verified`، وينطبق الشرط نفسه على طلبات العروض التي تُنشأ عبر API.

## 2. إنشاء مفتاح API

1. سجّل الدخول بحساب مسؤول الشركة وانتقل إلى **الإعدادات ← التكاملات وواجهة API**.
2. اضغط **إنشاء مفتاح API**.
3. سمِّه باسم الأداة التي ستستخدمه (مثال: `n8n procurement flow`).
4. حدد الصلاحيتين معًا: `copilot:chat` و`tender:create`.
5. **انسخ المفتاح الأصلي من الشاشة التي تظهر.** لن تتمكن من رؤيته مرة أخرى.

راجع [المصادقة](/docs/authentication) لمعرفة تفاصيل الصلاحيات وتدوير المفاتيح.

## 3. إنشاء تكامل

ما زلت في **الإعدادات ← التكاملات وواجهة API**:

1. اضغط **إنشاء تكامل**.
2. اختر القناة: **Webhook** (لـ n8n وMake وروبوتات المحادثة المخصصة) أو **MCP** (لـ Claude Desktop وCursor).
3. أعطه اسمًا، ويمكنك اختياريًا تعديل شخصية الوكيل (مثال: «تحدّث بأسلوب رسمي، وبالعربية دائمًا»).
4. انسخ رابط نقطة النهاية.

## 4. استدعاء الوكيل

### Webhook

```bash
curl -X POST https://<your-host>/integrations/webhook/<integrationId> \
  -H "X-Api-Key: bidc_live_<your-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "conversationId": "user-123-thread-456",
    "message": "We need a 3-month HR consulting engagement, budget 100k SAR"
  }'
```

ستحصل على رد الوكيل مع علامة `ready`. واصل إرسال الرسائل بنفس `conversationId` حتى تصبح `ready: true`، ثم اترك الإطلاق التلقائي يعمل (إن كان مفعّلًا) أو استدعِ نقطة نهاية الإطلاق صراحةً.

التفاصيل الكاملة: [واجهة API لـ Webhook](/docs/webhook).

### MCP

لاستخدام Claude Desktop أو Cursor، راجع مقتطفات الاتصال في [خادم MCP](/docs/mcp).

## 5. تتبّع ما يفعله تكاملك

عد إلى **الإعدادات ← التكاملات وواجهة API**، ثم افتح **النشاط الأخير** في أي تكامل لرؤية كل رسالة وكل حدث إطلاق مع الحالة وزمن الاستجابة ومعاينة لما أُرسل واستُقبل.
