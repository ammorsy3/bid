# حدود معدل الطلبات والأخطاء

## الحدود

| البند                             | الحد                       | ما يحدث عند بلوغه                            |
| --------------------------------- | -------------------------- | -------------------------------------------- |
| عدد الطلبات لكل مفتاح API         | 30 في الدقيقة              | `429` مع ترويسة `Retry-After` (بالثواني)      |
| حجم جسم الرسالة                   | 8 KB                       | `413` قبل أن نستدعي OpenAI                   |
| ذاكرة Idempotency المؤقتة         | 24 ساعة                    | تعيد الاستدعاءات المكررة الاستجابة الأصلية    |

الحدود مطبّقة على مستوى كل نسخة من الخادم وفي الذاكرة خلال مرحلة ما قبل التأسيس. إذا كنت شريك تصميم وتحتاج إلى حدود أعلى، أخبرنا وسنضبطها لكل مفتاح على حدة.

## رموز الأخطاء

تحمل جميع استجابات الأخطاء جسم JSON يتضمن على الأقل `{ "message": "..." }`، ومعه مصفوفة `validationErrors` المقروءة آليًا عند الاقتضاء.

| الحالة | المعنى                                                                      |
| ------ | --------------------------------------------------------------------------- |
| `400`  | حقل مطلوب مفقود أو بصيغة غير صحيحة                                           |
| `401`  | مفتاح API مفقود أو غير صالح الصيغة أو ملغى                                   |
| `403`  | التكامل معطّل، أو الشركة غير موثقة، أو الصلاحية غير ممنوحة                   |
| `404`  | التكامل أو الجلسة أو المحادثة غير معروفة                                     |
| `409`  | مسودة طلب العروض غير جاهزة للإطلاق بعد (راجع `validationErrors`)             |
| `413`  | جسم الطلب يتجاوز الحد الأقصى للحجم                                           |
| `429`  | تم تجاوز حد المعدل. انتظر عدد الثواني في `Retry-After` ثم أعد المحاولة.       |
| `5xx`  | حدث خلل من جانبنا. إعادة المحاولة آمنة — استخدم مفتاح Idempotency            |

## إعادة المحاولة الآمنة (Idempotency)

لأي استدعاء رسالة أو إطلاق قد تعيد محاولته (بسبب انتهاء مهلة الشبكة أو عقد إعادة المحاولة في n8n)، مرّر `idempotencyKey` ثابتًا في الجسم. تُخزَّن استجابة الاستدعاء الأول مؤقتًا لمدة 24 ساعة، وتعيد الاستدعاءات اللاحقة بالمفتاح نفسه الاستجابة المخزّنة (مع ترويسة `X-Idempotent-Replay: true`) بدل إعادة المعالجة.

```json
{
  "conversationId": "user-123-thread-456",
  "message": "...",
  "idempotencyKey": "msg-42-retry"
}
```

## المراقبة

يُسجَّل كل استدعاء خارجي في سجل نشاط التكامل مع الحالة وزمن الاستجابة ورمز الخطأ ومعاينة للطلب والاستجابة. راجع **الإعدادات ← التكاملات وواجهة API ← النشاط الأخير** عندما يبدو أن هناك خطأ ما.
