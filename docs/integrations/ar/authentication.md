# المصادقة

يعتمد كل تكامل خارجي (Webhook أو MCP أو API مباشر) على **مفتاح API** ينشئه مسؤول شركتك من **الإعدادات ← التكاملات**.

## إنشاء مفتاح

1. سجّل الدخول إلى لوحة تحكم Bid بحساب مسؤول الشركة.
2. انتقل إلى **الإعدادات ← التكاملات**.
3. اضغط **إنشاء مفتاح API**.
4. أعطه اسمًا واضحًا يسهل فهمه (مثال: `n8n procurement flow` و`Claude Desktop`).
5. حدد الصلاحيات التي تريد أن يحملها المفتاح. راجع القسم التالي.
6. اضغط **إنشاء المفتاح**. انسخ المفتاح الأصلي المعروض — **لن تراه مرة أخرى أبدًا**. نحن نخزّن تجزئته فقط.

## الصلاحيات

تحدد الصلاحيات ما يستطيع المفتاح فعله. امنح الحد الأدنى اللازم فقط.

| الصلاحية        | ما تسمح به                                                        |
| --------------- | ----------------------------------------------------------------- |
| `copilot:chat`  | التحدث مع وكيل مساعد Bid (إرسال الرسائل وقراءة الجلسات)            |
| `tender:create` | إنشاء طلبات عروض حقيقية من جلسة مكتملة                            |

المفتاح الذي لا يحمل `tender:create` يستطيع المحادثة وإعداد المسودات دون حد، لكنه لا يستطيع نشر طلب عروض. وهذا مفيد للاختبار.

## استخدام المفتاح

أرسله مع كل طلب بإحدى الطريقتين التاليتين:

- `X-Api-Key: bidc_live_<your-key>`
- `Authorization: ApiKey bidc_live_<your-key>`

## التدوير والإلغاء

لا يوجد تدوير للمفتاح في مكانه. لتدوير المفتاح:

1. أنشئ مفتاحًا جديدًا بالصلاحيات نفسها.
2. حدّث التكامل (n8n أو Make أو Claude Desktop) ليستخدم المفتاح الجديد.
3. تأكد أن الطلبات تمر عبر المفتاح الجديد (راجع **آخر استخدام** في الإعدادات).
4. ألغِ المفتاح القديم بالضغط على أيقونة سلة المهملات.

يسري الإلغاء **فورًا** — فأي طلب لاحق بهذا المفتاح يعيد `401`.

## حدود معدل الطلبات

- **30 طلبًا في الدقيقة لكل مفتاح API** (الافتراضي).
- **الحد الأقصى لحجم جسم الرسالة:** 8 KB.
- تجاوز أي من الحدين يعيد `429` (مع عدد الثواني في `Retry-After`) أو `413`.

إذا كنت تحتاج إلى حدود أعلى لأحد شركاء التصميم، تواصل معنا — يمكننا ضبطها لكل مفتاح على حدة.

## ما يراه الخادم

تُسجَّل الطلبات المصادَق عليها بمفتاح API في سجل نشاط شركتك مع الحقول التالية:

- `source = api_key | webhook | mcp`
- `apiKeyId`
- `integrationId` (عند المرور عبر تكامل Webhook أو MCP)
- `sessionId` (عند الارتباط بمحادثة)

يمكنك اكتشاف أي سلوك غير معتاد بمراجعة أحدث أحداث إنشاء طلبات العروض في عرض نشاط المسؤول.
